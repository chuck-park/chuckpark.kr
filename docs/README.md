# docs

이 폴더는 새 서비스 프로젝트의 문서를 역할 기준으로 나누기 위한 표준 구조입니다.

권장 읽기 순서:
1. `reference/docs-structure-guide.md`
2. `reference/document-roles.md`
3. `templates/`

상위 폴더 역할:
- `reference/`: 계속 참고하는 기준
- `strategy/`: 서비스 방향과 선택 기준
- `research/`: 인터뷰, 실험, 경쟁사 조사 같은 근거
- `decisions/`: ADR과 주요 결정 기록
- `prd/`: 무엇을 왜 만들지 정하는 요구사항
- `product/`: 실제로 어떻게 만들지 정하는 제품 설계
- `templates/`: 새 문서를 만들 때 복사할 템플릿
- `archive/`: 더 이상 정본이 아닌 문서 보관

실행 관점에서 별도 관리하는 루트 폴더:
- `evals/`: 에이전트 평가 케이스와 점수 기준
- `policies/`: 권한과 운영 정책
- `standards/`: 구조 규칙과 실패 분류
- `runs/`, `artifacts/`: 실행 결과물과 산출물
