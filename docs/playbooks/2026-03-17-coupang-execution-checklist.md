# Coupang Execution Checklist

작성일: 2026-03-17
목적: 농산물 판매를 쿠팡 중심으로 운영할 때 필요한 실행 항목을 주간 단위로 체크한다.

## 1. 사용 원칙

- SKU를 한 번에 많이 늘리지 않는다
- 잘 팔리는 3~5개 SKU에 집중한다
- 수정은 한 번에 많이 하지 않고, 한 변수씩 바꾼다
- 노출보다 중요한 것은 없다. 다만 노출만 보고 들어가지 않고 마진과 운영 난이도까지 같이 본다
- 운영 목표는 매출과 함께 업무시간 단축이다

## 2. 판매 전 체크

### 상품성

- 이 상품이 지금 팔릴 시즌인가
- 최소 2주 이상 안정적으로 소싱 가능한가
- 박스 파손, 변질, 클레임 가능성이 과도하지 않은가
- 마진이 플랫폼 수수료, 포장비, 택배비, 환불 리스크를 포함해도 남는가
- 차별화 포인트를 한 문장으로 말할 수 있는가

### 시장성

- 쿠팡에서 유사 키워드 검색 시 실제 판매 중인 상품이 충분히 있는가
- 검색 결과 상단 상품들의 가격대가 너무 무리하지 않은가
- 후기 수가 적당한 중간 경쟁 구간이 보이는가
- 완전 레드오션이거나 완전 무수요로 보이지 않는가

### 운영성

- 출고 리드타임을 현실적으로 맞출 수 있는가
- CS 답변에 필요한 기준 문구를 미리 만들 수 있는가
- 환불/교환 발생 시 손실을 감당 가능한가

## 3. 상품 등록 체크

### 상품명

- 핵심 키워드가 앞부분에 들어갔는가
- 고객이 실제 검색할 표현을 썼는가
- 불필요한 수식어를 과하게 넣지 않았는가
- 품종, 산지, 용량, 포장 단위가 명확한가

### 대표이미지

- 상품이 무엇인지 1초 안에 이해되는가
- 배경과 피사체가 분리되어 보이는가
- 텍스트를 넣더라도 과하지 않은가
- 묶음 수량, 중량, 옵션 차이가 헷갈리지 않는가

### 상세페이지

- 첫 화면에서 상품 핵심 장점이 바로 보이는가
- 산지, 품종, 중량, 상태, 배송 정보가 빠지지 않았는가
- 보관법과 섭취 팁이 있는가
- 환불/교환 기준이 명확한가
- 고객이 망설일 질문을 FAQ로 미리 답했는가

### 가격/옵션

- 가격이 시장 대비 완전히 튀지 않는가
- 옵션이 과도하게 복잡하지 않은가
- 잘 팔릴 메인 옵션이 분명한가

## 4. 런칭 첫 7일 체크

### 매일 확인

- 방문자 수
- 조회 수
- 장바구니 수
- 주문 수
- 전환율
- 문의 수
- 배송 지연 여부

### 바로 수정할 것

- 클릭이 너무 낮으면 상품명/대표이미지/가격 우선 점검
- 클릭은 되는데 전환이 낮으면 상세페이지/옵션/신뢰 문구 점검
- 문의가 반복되면 상세페이지와 FAQ에 즉시 반영
- 배송 이슈가 생기면 판매 확장보다 운영 정상화가 먼저

### 하지 않을 것

- 런칭 직후 모든 요소를 동시에 바꾸기
- 성과 확인 전에 SKU를 계속 추가하기
- 마진 계산 없이 쿠폰과 할인만 반복하기

## 5. 주간 운영 체크

### 매주 1회

- 상위 3개 SKU와 하위 3개 SKU 분리
- 전환 낮은 상품 1개만 개선 대상 선정
- 반복 문의 5개 추출
- 후기에서 자주 언급되는 표현 추출
- 다음 주 밀 SKU 1개 결정

### 개선 우선순위

1. 배송/품질 문제
2. 대표이미지
3. 상품명
4. 상세페이지 첫 화면
5. 옵션 구조
6. 가격

## 6. 손실 최소화 체크

- 출고 누락이 없는가
- 오배송 가능성이 있는 상품은 라벨링이 명확한가
- 클레임이 예상되는 품목은 안내문구가 충분한가
- 부분환불, 재발송, 교환의 기준을 미리 정해두었는가
- 소싱처와 책임 구간이 정리되어 있는가

## 7. 운영 시간 단축 체크

- 발주 시간은 하루 1회로 묶을 수 있는가
- 운송장 등록 시간을 특정 시간대로 고정할 수 있는가
- 반복 문의 답변을 템플릿으로 만들었는가
- 상품 설명 초안 생성을 자동화했는가
- SNS 콘텐츠 초안을 SKU별로 재사용하고 있는가

## 8. 주말 리뷰 질문

- 이번 주 가장 잘 팔린 이유는 무엇인가
- 가장 많이 들어온 고객 질문은 무엇인가
- 다음 주에 더 밀어야 할 SKU는 무엇인가
- 당장 줄여야 할 작업은 무엇인가
- 자동화할 가치가 가장 큰 반복 작업은 무엇인가
