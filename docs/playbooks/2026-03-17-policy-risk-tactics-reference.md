# Policy Risk Tactics Reference

작성일: 2026-03-17
목적: PDF와 시장 관행에서 자주 언급되는 정책 리스크 방식들을 정리하되, 실행 가이드가 아니라 위험 참고 문서로만 사용한다.

## 1. 이 문서의 원칙

- 이 문서는 실행 방법을 알려주는 문서가 아니다
- 주인님이 실수로 계정 리스크를 키우지 않도록 위험 신호를 구분하는 목적이다
- 실제 정책 해석은 항상 최신 쿠팡 공식 문서를 우선 확인한다
- 리스크가 높은 방식은 단기 매출이 아니라 계정 안정성과 장기 사업성 관점에서 배제한다

## 2. 고위험 방식

### 가구매 / 허위 주문 / 실적 조작

설명:
- 실제 고객 수요가 아닌 주문을 만들어 클릭, 구매, 전환 지표를 인위적으로 올리는 방식

왜 위험한가:
- 검색 실적 조작으로 해석될 수 있다
- 계정 제재, 정산 보류, 상품 비노출 위험이 있다
- 내부 데이터가 오염돼 실제로 잘 팔리는 상품 판단을 망친다

대체 방향:
- 소량 광고 테스트
- 실제 고객 후기와 문의 기반 개선
- 상품 경쟁력과 상세페이지 개선

### 허위 리뷰 / 대가성 리뷰 유도

설명:
- 구매하지 않은 사람의 리뷰를 붙이거나, 리뷰 조건으로 부당한 혜택을 제공하는 방식

왜 위험한가:
- 리뷰 신뢰도를 무너뜨린다
- 플랫폼 정책 위반 가능성이 높다
- 후기 채널 전체가 무력화된다

대체 방향:
- 실제 구매 고객의 사용 경험을 자연스럽게 유도
- FAQ와 상세페이지 개선으로 후기 의존도를 낮춤

### 키워드 미스매치 등록

설명:
- 실제 상품과 맞지 않는 인기 키워드를 상품명, 태그, 옵션에 과도하게 넣는 방식

왜 위험한가:
- 클릭은 생겨도 전환이 무너질 수 있다
- 고객 기대와 실제 상품이 어긋나 반품과 불만이 늘어난다
- 장기적으로 검색 적합성을 해친다

대체 방향:
- 고객 검색 의도와 실제 상품이 일치하는 키워드만 사용
- 메인 키워드와 보조 키워드를 분리 관리

### 현실을 벗어난 출고 약속

설명:
- 실제 공급과 물류가 감당되지 않는데도 공격적으로 출고 기준을 잡는 방식

왜 위험한가:
- 배송지연, CS 폭증, 취소 증가로 바로 운영이 무너진다
- 초기 판매 실적과 계정 신뢰도에 악영향을 준다

대체 방향:
- 현실적으로 맞출 수 있는 출고 기준만 사용
- 판매 확장보다 출고 안정화 우선

## 3. 중위험 방식

### 가격 급변 반복

설명:
- 노출과 클릭 반응을 보기 위해 가격을 너무 자주 흔드는 방식

왜 위험한가:
- 고객 신뢰가 떨어진다
- 마진 계산이 꼬인다
- 어떤 변화가 성과를 만들었는지 해석이 어려워진다

대체 방향:
- 주간 단위로만 가격 실험
- 가격 외 요소와 분리해서 테스트

### 쿠폰 남발

설명:
- 클릭과 전환을 올리기 위해 쿠폰을 과도하게 넣었다 빼는 방식

왜 위험한가:
- 마진이 무너질 수 있다
- 실제 고객층이 가격 민감 고객으로만 쏠릴 수 있다
- 반복 운영 기준이 흐려진다

대체 방향:
- 마진 범위 안에서 제한적으로만 사용
- 대표 SKU에만 테스트

### 과장 상세페이지

설명:
- 실제 상태보다 훨씬 좋아 보이게 쓰거나, 자연물 편차를 숨기는 방식

왜 위험한가:
- 초기 전환은 오를 수 있어도 반품과 컴플레인이 늘어난다
- 신선식품은 기대치 관리 실패가 손실로 바로 이어진다

대체 방향:
- 자연물 특성을 먼저 설명
- 상태 편차, 보관법, 수령 직후 확인 포인트를 명시

## 4. 저위험이지만 주의가 필요한 방식

### 체험단 운영

설명:
- 상품 인지도와 첫 반응을 얻기 위한 샘플 배포나 체험단 운영

주의점:
- 리뷰 강요나 조건부 보상 구조로 흐르면 위험해진다
- 샘플링과 리뷰 정책은 분리해서 봐야 한다

대체 방향:
- 제품 피드백 수집 목적과 후기 노출 목적을 구분
- 실제 정책상 허용 범위를 먼저 확인

### 경쟁사 모니터링

설명:
- 경쟁 상품의 가격, 이미지, 키워드, 후기 패턴을 관찰하는 것

주의점:
- 표절이나 오해 유도까지 가면 문제다
- 참고는 하되, 그대로 복제하지 않는다

대체 방향:
- 구조는 참고하고 메시지와 포지셔닝은 차별화

## 5. 주인님 방식에 맞는 배제 원칙

주인님은 아래 방식은 기본 전략에서 제외한다.

- 실적 조작으로 해석될 수 있는 방식
- 리뷰 신뢰를 해치는 방식
- 현실적 출고 능력을 넘어서는 약속
- 상품과 맞지 않는 키워드 유입 유도
- 장기적으로 고객 신뢰를 해치는 과장 문구

## 6. 의사결정 체크 질문

- 이 행동이 쿠팡 계정 제재 사유로 해석될 여지가 있는가
- 이 행동이 고객에게 들켰을 때 설명 가능한가
- 이 행동이 매출보다 더 큰 운영 손실을 만들 수 있는가
- 이 행동이 내 데이터를 왜곡시켜 다음 판단을 망치지 않는가

하나라도 크게 걸리면 하지 않는다.

## 7. 주인님에게 맞는 실무 결론

- 단기 노출 요령보다 상품-키워드 적합도와 운영 안정성이 더 중요하다
- 개발 역량은 조작 도구가 아니라 운영 효율화 도구에 쓴다
- 위험한 방식은 연구 대상일 수는 있어도 운영 기준이 되면 안 된다
