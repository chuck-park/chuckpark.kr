# Coupang Detail Page Template

작성일: 2026-03-17
목적: 농산물 쿠팡 상세페이지를 반복 가능하게 작성하기 위한 기준 템플릿

## 1. 기본 원칙

- 상세페이지는 예쁘게 만드는 것보다 빠르게 이해되게 만드는 것이 우선이다
- 첫 화면에서 상품명, 핵심 장점, 품종/산지/중량이 보여야 한다
- 고객이 망설이는 지점을 미리 없애는 방향으로 쓴다
- 과장 표현보다 검증 가능한 설명을 우선한다

## 2. 상품명 템플릿

형식:

`[핵심 키워드] [품종/산지] [핵심 장점] [중량/수량]`

예시:

- `참외 성주 고당도 로얄과 3kg`
- `딸기 설향 특대과 750g 2팩`
- `구좌당근 제주 흙당근 중품 5kg`

점검:

- 핵심 키워드가 앞에 있는가
- 고객이 실제로 검색하는 단어인가
- 옵션 구분이 명확한가

## 3. 대표이미지 템플릿

### 이미지 1

- 상품 전체가 잘 보이는 정면 이미지
- 메인 옵션 기준으로 촬영
- 텍스트는 최소화

### 이미지 2

- 단면, 크기, 알 수, 포장 상태 등 실구매 판단에 필요한 정보

### 이미지 3

- 산지 또는 선별 과정

### 이미지 4

- 배송 상태, 포장 방식

### 이미지 5

- 보관법 또는 섭취 팁

## 4. 상세페이지 기본 구조

### 섹션 1. 한눈에 이해

- 상품명
- 핵심 장점 3개
- 산지
- 품종
- 중량/수량
- 추천 고객

예시 문장:

- `당도와 향이 좋은 제철 상품입니다.`
- `가정용으로 먹기 좋은 기본 구성입니다.`
- `선물용보다 실속형 구매에 맞습니다.`

### 섹션 2. 왜 이 상품인가

- 왜 이 상품을 골랐는지
- 어떤 기준으로 소싱했는지
- 일반 상품과 차이가 무엇인지

예시 문장:

- `무조건 최저가보다는 상태와 선별 안정성을 우선했습니다.`
- `초기 불량률을 줄이기 위해 포장 상태를 먼저 확인하는 공급처만 선택합니다.`

### 섹션 3. 상품 정보

- 산지
- 품종
- 중량
- 구성
- 옵션 차이
- 수확/출고 기준

### 섹션 4. 맛과 상태 설명

- 어떤 맛인지
- 어떤 식감인지
- 어떤 상태로 도착할 수 있는지
- 자연물 특성상 생길 수 있는 편차

예시 문장:

- `과육 단단함은 수확 시점과 날씨에 따라 조금 달라질 수 있습니다.`
- `자연물 특성상 크기와 색은 일정하지 않을 수 있습니다.`

### 섹션 5. 보관법 / 먹는 방법

- 실온/냉장 보관 기준
- 권장 섭취 시점
- 손질 팁

### 섹션 6. 배송 안내

- 출고 요일
- 예상 도착 구간
- 택배 특성상 주의사항
- 수령 직후 확인 포인트

### 섹션 7. 교환 / 환불 안내

- 어떤 경우 사진이 필요한지
- 어떤 기준으로 재발송/환불이 가능한지
- 수령 직후 확인 요청 문구

## 5. FAQ 템플릿

- `보관은 어떻게 해야 하나요?`
- `선물용으로도 괜찮나요?`
- `일부 상태가 좋지 않으면 어떻게 해야 하나요?`

## 6. 상세페이지 작성 체크

- 첫 화면에 핵심 정보가 다 있는가
- 고객 불안 요소를 먼저 풀어주는가
- 배송과 보관 안내가 빠지지 않았는가
- 과장 문구 없이도 강점이 전달되는가
- 자주 받는 질문이 반영되어 있는가
