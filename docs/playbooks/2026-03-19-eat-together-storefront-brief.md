# 같이먹개 / eat together 자사몰 구축 브리프

목적: 새 프로젝트에서 같이먹개 자사몰을 빠르게 착수하기 위한 MVP 기준 문서

## 1. 프로젝트 정의

같이먹개 자사몰은 당장 스마트스토어를 대체하는 메인 매출 채널이 아니라,
브랜드 신뢰와 직접 고객 접점을 쌓는 자산 채널이다.

따라서 초반 목표는 다음과 같다.

- 브랜드 인상 형성
- 제철 상품 구매 흐름 확보
- 반복 구매 여지 만들기
- 스마트스토어와 역할 분리

## 2. 목표

### 1차 목표

- 브랜드가 무엇인지 한 화면에서 이해된다
- 핵심 상품 3~5개를 구매 또는 문의 가능 상태로 연다
- 산지, 소싱 기준, 보관법, FAQ가 정리되어 있다

### 2차 목표

- 묶음 상품, 기획전, 선물 수요를 받는다
- 반복 구매 고객을 모은다
- 스마트스토어 유입 고객의 재방문 채널이 된다

## 3. MVP 범위

- 메인 페이지
- 상품 목록
- 상품 상세
- 장바구니/구매 흐름
- 배송/교환/환불 안내
- 브랜드 소개
- 문의/고객응대 채널

후순위:
- 회원제
- 포인트
- 정기구독
- 개인화 추천
- 고급 자동화

## 4. 정보 구조

### 메인 네비게이션

- Home
- 제철 상품
- 함께 즐기기 좋은 상품
- 선물/세트
- 브랜드 이야기
- 고객안내

### 메인 페이지 섹션

1. 히어로
- 브랜드명: 같이먹개
- 슬로건: 사람과 강아지가 함께 즐기는 농산물 라이프
- 메인 CTA: 제철 상품 보기

2. 오늘의 셀렉션
- 핵심 상품 3~5개

3. 왜 같이먹개인가
- 사람이 먹는 기준
- 산지와 선별 기준
- 함께 즐기기 좋은 방식 제안

4. 함께 즐기는 팁
- 보관법
- 손질법
- 자주 묻는 질문

5. 후기/스토리
- 고객 반응
- 산지 이야기
- 계절 콘텐츠

6. 문의/안내
- 배송
- 교환/환불
- 고객응대 채널

## 5. 콘텐츠 원칙

- 상품 사진보다 먼저 신뢰 포인트를 준다
- 산지, 원산지, 중량, 선별 기준을 빠뜨리지 않는다
- 반려견 관련 내용은 정보성으로만 다룬다
- “함께 먹기 좋다”는 표현은 가능하지만 “안전 보장”처럼 들리면 안 된다

## 6. 카피 기준

### 해야 할 표현

- 사람이 먹는 기준으로 고른
- 제철에 맞춰 선별한
- 함께 즐기기 좋은 방식까지 제안하는
- 산지와 보관 기준을 분명히 안내하는

### 피해야 할 표현

- 강아지도 반드시 먹을 수 있는
- 건강에 좋은
- 치료, 예방, 개선
- 반려견 전용 식품처럼 보이는 표현

## 7. 기술 방향

새 프로젝트에서 직접 구축할 경우 추천 기준:

- 프레임워크: Next.js
- 언어: TypeScript
- 스타일링: Tailwind CSS
- 배포: Vercel
- 결제: 국내 PG 연동 가능한 구조
- 관리자/데이터: 초기에는 간단한 관리 방식 우선

핵심은 고도화보다 빠른 오픈이다.
브랜드/상품/FAQ/구매 흐름이 먼저고, 자동화는 이후 단계에서 붙인다.

## 8. 데이터 모델 초안

### 상품

- 상품명
- 시즌 태그
- 대표 이미지
- 원산지
- 중량/규격
- 판매가
- 보관 방법
- 맛 포인트
- 출고 기준
- FAQ
- 반려생활 관련 안내 문구

### 브랜드 스토리

- 왜 이 상품을 파는지
- 어떤 기준으로 고르는지
- 일반 상품과 무엇이 다른지

## 9. 운영 연동 원칙

- 스마트스토어와 상품 역할을 분리한다
- 자사몰은 브랜드형 기획전과 묶음 구성을 더 강조한다
- 스마트스토어에서 유입된 고객이 재구매할 이유를 만든다
- 자사몰 전용 혜택은 과도한 할인보다 경험 차이로 만든다

## 10. 2주 착수 계획

### 1주차

- 브랜드 카피 확정
- 메인페이지 구조 확정
- 상품 3~5개 정보 정리
- 배송/반품/FAQ 문구 정리

### 2주차

- 메인, 목록, 상세, 고객안내 페이지 제작
- 상품 등록
- 구매 흐름 점검
- 모바일 레이아웃 검수

## 11. 완료 기준

- 브랜드명이 한눈에 보인다
- 핵심 상품 구매 흐름이 동작한다
- 상품 상세에 신뢰 정보가 충분히 있다
- 고객안내와 문의 채널이 분명하다
- 스마트스토어와 역할 차이가 설명된다

## 12. 새 프로젝트 킥오프 시 질문

- 이번 자사몰의 목표는 판매인가, 신뢰인가, 재구매인가
- 첫 오픈 SKU는 무엇인가
- 묶음/선물형 상품을 같이 열 것인가
- CMS가 필요한가, 코드 관리로 충분한가
- 반려견 관련 가이드를 어느 수준까지 노출할 것인가
