# Agriculture Execution Roadmap

작성일: 2026-03-17
기준 기간: 2026-03-17 ~ 2026-06-30
목적: 농산물 판매를 현금흐름 우선 사업으로 운영하기 위한 실행 계획

## 1. 이번 로드맵의 기준

- 메인 사업은 농산물 판매다
- 쿠팡은 단기 매출 채널이다
- 자사몰은 장기 고객 자산 채널이다
- SNS는 판매 보조 채널이다
- 개발은 운영 효율과 콘텐츠 생산성 향상을 위한 내부 도구에 먼저 투입한다

## 2. 2026년 6월까지 핵심 지표

### 매출/운영

- 핵심 SKU 3~5개 확정
- 쿠팡 판매용 상세페이지 템플릿 1세트 완성
- 반응 좋은 콘텐츠 포맷 3개 확보
- 반복 작업 자동화 2개 완료
- 자사몰 최소 오픈

### 확인할 숫자

- SKU별 클릭률
- SKU별 전환율
- 상품별 마진
- 재구매 가능성
- 고객 문의 유형
- 콘텐츠별 유입 기여

## 3. 쿠팡 운영 로드맵

### 목표

- 회전 빠른 SKU를 찾는다
- 상세페이지와 상품명을 표준화한다
- 상품 등록/운영 프로세스를 반복 가능하게 만든다

### 1단계: SKU 선정

- 현재 소싱 가능한 품목 전부 나열
- 각 품목별로 마진, 보관성, 배송 난이도, 계절성, 차별점 점검
- 우선 테스트 SKU 3~5개로 압축

### 2단계: 상품 등록 구조화

- 상품명 템플릿 작성
- 이미지 구성 템플릿 작성
- 상세설명 구조 템플릿 작성
- FAQ와 구매 유도 문구 정리

### 3단계: 운영 지표화

- 상품별 매출 추적 표 만들기
- 클릭률과 전환율 비교 표 만들기
- 리뷰와 문의를 유형별로 모으기
- 반품/불만 원인을 누적 기록

### 주간 반복 체크

- 지난주 판매 상위 3개 확인
- 전환 낮은 상품 1개만 집중 수정
- 문의/리뷰에서 반복된 표현 추출
- 다음 주 프로모션 대상 SKU 1개 결정

## 4. 자사몰 로드맵

### 목표

- 당장 큰 매출보다 브랜드 자산과 직접 고객 접점을 확보한다
- 쿠팡에서 검증된 상품을 자사몰에서도 반복 구매 가능한 구조로 둔다

### MVP 범위

- 메인 페이지
- 상품 목록
- 상품 상세
- 구매 흐름
- 배송/교환 안내
- 문의 채널

### 필수 콘텐츠

- 왜 이 상품을 파는지
- 산지와 소싱 기준
- 품질 차이
- 보관법
- 먹는 방법
- 자주 묻는 질문

### 우선순위

- 디자인 완성도보다 구매 흐름과 신뢰 문구 우선
- 상품 수를 많이 늘리지 말고 핵심 SKU 중심
- 쿠팡과 자사몰의 역할 차이를 분명히 한다

## 5. SNS 콘텐츠 로드맵

### 목표

- 팬 형성보다 판매 연결
- 신뢰 형성, 상품 이해, 구매 망설임 해소

### 핵심 포맷 3개

- 상품 소개형
  - 어떤 상품인지
  - 왜 지금 사야 하는지
  - 어떤 사람이 만족할지

- 산지/소싱형
  - 어디서 왔는지
  - 어떤 기준으로 골랐는지
  - 일반 상품과 차이가 무엇인지

- 운영/후기형
  - 실제 반응
  - 발송 과정
  - 고객 후기
  - 자주 받는 질문

### 주간 발행 기준

- 상품 소개 2개
- 산지/소싱 1개
- 후기/운영 1개
- 필요시 프로모션 1개

### 운영 원칙

- 콘텐츠 하나가 SKU 하나를 밀도록 만든다
- 추상적 브랜딩보다 구매 근거를 준다
- 매 게시물마다 문의 또는 구매 행동을 유도한다

## 6. 자동화 기능 우선순위

### 1순위

- 쿠팡 상품명/상세설명 초안 생성기
- SNS 콘텐츠 초안 생성기

### 2순위

- 경쟁 상품 관찰용 정리 도구
- 후기/문의 분류 도구

### 3순위

- 자사몰 상품 등록 보조 도구
- 마케팅 카피 변형 도구

### 판단 기준

- 주 2회 이상 반복되는가
- 30분 이상 걸리는가
- 매출 또는 전환에 직접 영향을 주는가

## 7. 4주 실행 체크리스트

### 1주차

- 테스트 SKU 3~5개 확정
- 상품별 마진과 배송 난이도 점검
- 쿠팡 템플릿 초안 작성

### 2주차

- 상품 등록 구조 통일
- 상세페이지 기준안 작성
- 자사몰 정보 구조 초안 작성

### 3주차

- 자동화 도구 1개 착수
- SNS 콘텐츠 포맷 3개 실제 발행
- 상품 설명 자산 모으기

### 4주차

- 판매 데이터 리뷰
- 전환 낮은 상품 개선
- 자사몰 MVP 착수 또는 공개

## 8. 90일 체크포인트

### 4월 말

- 어떤 SKU가 가장 반응이 좋은지 파악
- 상세페이지/상품명 템플릿 1차 확정
- 콘텐츠 포맷 3개 중 반응 좋은 것 선별

### 5월 말

- 자동화 2개 중 1개 실사용 단계 진입
- 자사몰 최소 오픈 또는 오픈 직전 상태
- 반복 문의와 후기 패턴 정리

### 6월 말

- 핵심 SKU와 채널 역할 확정
- 운영 루틴이 수작업에서 반자동으로 전환
- 하반기 확장 여부 판단

## 9. 하지 않을 것

- 2026년 6월 전까지 새 사업을 많이 벌리지 않는다
- 외부 셀러용 SaaS를 바로 만들지 않는다
- 브랜딩 욕심 때문에 판매 우선순위를 흐리지 않는다
- SKU를 과하게 늘리지 않는다
