# Agriculture-First Business Roadmap

작성일: 2026-03-17
대상: 2026년 6월까지 현금흐름 우선, 농산물 판매 중심, 개발 역량 결합 전략

## 1. 한 줄 전략

2026년 6월까지는 AI 빌더 브랜딩보다 농산물 판매를 현금흐름 엔진으로 우선한다.
개발 역량은 별도 사업의 메인이 아니라, 쿠팡 판매 운영, 자사몰 구축, 콘텐츠 생산, 마케팅 자동화를 증폭하는 도구로 사용한다.

## 2. 핵심 목표

### 2026년 6월까지의 1차 목표

- 농산물 판매를 기반으로 월 현금흐름을 빠르게 만든다
- 잘 팔리는 핵심 SKU와 운영 구조를 확정한다
- 쿠팡 판매와 자사몰 운영에 필요한 반복 작업을 자동화한다
- SNS와 콘텐츠는 직접 매출과 신뢰 형성에 연결되는 수준으로만 운영한다

### 장기 목표

- 농산물 판매 운영 체계를 자산화한다
- 내부적으로 만든 운영 도구를 추후 외부 서비스나 교육으로 확장할 수 있게 만든다
- AI agent 브랜딩은 현금흐름이 안정된 뒤 다시 키운다

## 4. 포지셔닝

### 메인 포지션

개발과 자동화를 활용해 농산물 판매를 효율적으로 운영하는 실행형 판매자

### 보조 포지션

- 소싱, 판매, 마케팅, 자사몰 운영을 함께 설계하는 농산물 사업 운영자
- 반복 작업을 자동화하고 데이터를 활용해 판매 효율을 높이는 메이커
- 장기적으로는 이 경험을 바탕으로 AI agent 기반 운영 시스템을 만드는 사람

## 5. 프로젝트별 역할

### 농산물 판매

- 2026년 6월까지의 메인 현금흐름 엔진
- 가장 우선순위가 높은 사업

### 농산물 자사몰

- 직접 매출보다 브랜드 자산과 고객 DB 확보 목적
- 반복 구매와 장기 고객 관계를 위한 기반

### 쿠팡 판매

- 단기 매출 확보용 메인 플랫폼
- 상품 검증, 가격 검증, 상세페이지 검증의 실전 무대

### SNS 콘텐츠

- 브랜딩용이 아니라 판매 보조용 채널
- 상품 신뢰, 산지 스토리, 보관법, 차별점, 후기 확산 목적

### 호랑사주 / 광고형 앱 / AI 빌더 콘텐츠

- 2026년 6월까지는 후순위
- 완전히 중단하지는 않되, 메인 현금흐름 사업을 방해하지 않는 수준에서만 유지

## 6. 수익화 우선순위

### 1순위: 농산물 판매 매출

가장 빠르게 현금흐름으로 연결될 가능성이 높다.
이미 경험이 있는 시장이므로 학습비용이 낮다.

### 2순위: 농산물 판매 운영 효율화

직접적인 매출은 아니지만 마진과 시간 효율을 높인다.
개발 역량은 여기에 가장 먼저 투입한다.

### 3순위: 자사몰과 반복 구매 구조

플랫폼 의존도를 낮추고 장기적으로 안정성을 높인다.

### 4순위: AI 빌더 브랜딩 / 외주 / 교육

장기적 옵션으로 유지하되, 2026년 6월 전까지는 메인 목표로 두지 않는다.

## 7. 개발 역량을 투입할 영역

개발은 별도 제품 사업으로 바로 확장하지 않는다.
먼저 내 판매 운영에 쓰는 내부 도구로 사용한다.

### 우선 개발 후보

- 쿠팡 상품명/키워드/상세설명 초안 생성기
- 경쟁 상품 관찰용 대시보드
- 상품별 마케팅 카피 생성기
- SNS 콘텐츠 초안 자동 생성기
- 자사몰 상품 등록 보조 도구
- 반복 문의/후기/클레임 분류 도구

### 원칙

- 상위노출 조작 도구를 만들지 않는다
- 상품 품질, 전환율, 운영 효율, 콘텐츠 생산성 개선에 집중한다
- 외부 SaaS로 확장하는 것은 내부 효용이 검증된 뒤 검토한다

## 8. 채널별 역할

### 쿠팡

단기 매출 확보용 핵심 채널

집중 요소:
- 잘 팔리는 SKU 선정
- 상품명, 이미지, 상세페이지
- 가격 경쟁력
- 배송/재고/운영 안정성
- 리뷰와 고객 대응

### 자사몰

장기 자산 채널

집중 요소:
- 브랜드 설명
- 산지/상품 스토리
- 반복 구매 유도
- 고객 연락처와 관계 축적

### SNS

판매 보조 채널

추천 포맷:
- 오늘 들어온 상품
- 산지 이야기
- 맛과 차이점 설명
- 보관법
- 고객 후기
- 발송 및 선별 과정

### chuckpark.kr

2026년 6월까지는 주 사업 허브가 아니라 보조 자산

역할:
- 개인 브랜딩 기록
- 향후 빌더/외주/콘텐츠 확장용 기반
- 당장 최우선 개편 대상은 아님

## 9. 콘텐츠 전략

콘텐츠는 팬 형성보다 판매 연결을 우선한다.

### 메인 콘텐츠

- 상품 소개
- 산지와 소싱 기준
- 왜 이 상품을 선택했는지
- 보관법과 먹는 방법
- 고객 후기와 실제 반응
- 시즌성 이슈와 구매 타이밍

### 보조 콘텐츠

- 쿠팡 상세페이지 개선 기록
- 자사몰 제작 과정
- 마케팅 자동화 실험
- 판매 데이터를 보고 배운 점

### 후순위 콘텐츠

- 해외 SaaS 성공사례 분석
- AI agent 중심 장기 브랜딩 콘텐츠

## 10. 2026년 6월까지의 완료 조건

### 판매 측면

- 핵심 SKU 3~5개 확정
- 쿠팡 중심 매출 흐름 확보
- 재주문 가능성이 있는 상품군 식별

### 운영 측면

- 반복 작업 2개 이상 자동화
- 상품 등록/상세페이지 제작 템플릿 확보
- SNS 콘텐츠 초안 생산 루틴 구축

### 자산 측면

- 농산물 자사몰 최소 오픈
- 상품 소개 구조와 기본 구매 흐름 완성
- 고객 접점 채널 확보

## 11. 30일 실행안

### 1주차

- 판매 가능한 후보 SKU 정리
- 현재 소싱 가능 품목과 마진 구조 점검
- 쿠팡 판매 우선 상품 3~5개 선정

### 2주차

- 쿠팡용 상품명, 이미지, 상세설명 템플릿 정리
- 경쟁 상품 관찰 기준 정리
- 자사몰 구조 초안 설계

### 3주차

- 첫 내부 자동화 도구 1개 착수
- SNS 콘텐츠 포맷 3개 정의
- 산지/상품 설명용 기본 콘텐츠 제작

### 4주차

- 쿠팡 판매 성과 점검
- 전환이 낮은 상품 상세 개선
- 자사몰 MVP 착수

## 12. 90일 실행안

### 1단계: 현금흐름 확보

- SKU를 넓히지 말고 핵심 상품에 집중
- 쿠팡 중심으로 빠르게 판매 데이터 확보
- 운영 문제를 먼저 해결

### 2단계: 운영 자동화

- 가장 많이 반복되는 작업 2개 자동화
- 상세페이지 제작과 SNS 초안 생성을 우선순위로 둔다

### 3단계: 자사몰과 고객 자산 축적

- 자사몰 최소 오픈
- 기존 고객과 SNS 유입을 활용해 직접 판매 실험
- 반복 구매 가능성 확인

### 4단계: 후속 확장 검토

- 내부 도구가 반복 효용이 크면 추후 서비스화 검토
- AI 빌더 브랜딩은 하반기 이후 다시 강화

## 13. 운영 원칙

- 2026년 6월까지는 농산물 판매가 메인 사업이다
- 개발은 판매를 돕는 수단으로 사용한다
- 새 사업을 많이 벌리기보다 잘 팔리는 상품에 집중한다
- 브랜딩보다 매출과 운영 안정성을 먼저 본다
- 플랫폼 의존도를 줄이되, 단기 매출은 쿠팡 중심으로 확보한다
- 자사몰은 당장 큰 매출보다 고객 자산 축적 목적에 둔다
